# Ifrah Awaale · Systems Portfolio

**Live page: https://ifrah87.github.io/portfolio/**

Two systems built to run a mixed-use building: its money and its cleaning.

- **Finance Platform**: bookings, leases, meter readings, billing and bank reconciliation on a double-entry ledger, where the bank statement is the only way a bill gets paid.
- **Cleaning Operations App**: daily round scheduling, attendance from the door system, and a live board on the staff-room TVs.
- **Exception Reporting**: checks that every tenancy was billed once, and that the ledger agrees with the bills.
- **The Stack**: TypeScript / Next.js, Postgres, Supabase, SQL, and what would change at scale.

All interface examples on the page use invented demo data.
